# The Blind Artist aka HOPSY'S ART SPEEDRUN

Hi its past Hopsy! 

This goofy mod was made as content for content. If you are playing it for fun good luck lol! The intention is that you have Going Blind on and Joker Display off, so that it is sort of a puzzle to decipher which joker is which based on my beautiful drawings.

I speedran this texture pack in 2:43:39.15! Kinda slow but you will be able to see the love and effort in each joker that might make you marvel at just how quickly I was able to make such a beautiful piece of art.

Malverk is necessary to load the texture pack, most people already have it, and if so, feel no need to use the provided file.

The recommended experience involves using the attached mod Going Blind, and turning off Joker Display and the calculator. However if you want to just enjoy the beautiful art and not feel punished for a lack of artistic eye yourself, feel free to not use that mod as well!
